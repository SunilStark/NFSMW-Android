# Changelog

## 0.8.1 — 2026-10-27

- Gestor de partidas con ZIP, respaldo previo, SHA-256/CRC y recuperación de reemplazos interrumpidos.
- Preservación de configuración, recursos y cachés al importar; operaciones bloqueadas mientras hay sesión activa.
- Perfiles Batería, Equilibrado, Rendimiento y Calidad con restauración de ajustes personales.
- Documentación actualizada de arquitectura, compatibilidad, compilación, resultados y pendientes.
- Validación por build Release y pruebas de código; sin dispositivo ni emulador en esta entrega.

## 0.8.0 — 2026-10-26

- Integración del propietario del backend GLES, shaders separados, opciones de compatibilidad y LAN experimental.
- Conserva el launcher, controles, paquete y rutas del proyecto. Base para la entrega 0.8.1.
